# 🛒 Bazar Dor (বাজার দর)

A web platform designed to provide transparent, daily market prices for essential agricultural commodities across Bangladesh, helping consumers and vendors track price fluctuations.

![Bazar Dor Preview](./Screenshot%202026-10-29%20215225.png)

---

### 🚀 Live Demo
- **Live URL:** [https://assignment-007-five.vercel.app](https://assignment-007-five.vercel.app)

---

### ✨ Features
- **Real-Time Commodity Tracking:** Daily updated rates for vegetables, grains, and essentials.
- **Price Trend Visualizations:** Interactive charts illustrating week-over-week trends.
- **Category Filtering:** Quick search and filtering by produce categories and districts.
- **Fast Server-Side Rendering:** Optimized load times using Next.js caching and data fetching.

---

### 🛠️ Tech Stack & Dependencies
- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Node.js, Express / Next.js API Routes
- **Database:** MongoDB Atlas (Mongoose ODM)
- **Charts:** Chart.js / Recharts
- **Deployment:** Vercel
